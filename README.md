# 和巴辞典・文章メーカー

日常の日本語を入力すると、パーリ語の候補が出る一方向の辞書ツールです。お釈迦様が実際に生きておられた言語の空間に、少しでも近づくために作りました。

**インターネットに接続しなくても使えます。** 単一のHTMLファイル（約16MB）で動作します。

## 使い方

- **そのままブラウザで使う**: GitHub Pages のページを開く（公開URLは下記）
- **オフラインで使う**: [Releases](../../releases) から `pali-dictionary-and-sentence-maker.html` をダウンロードし、ブラウザで開く

公開URL: `https://（ユーザー名）.github.io/（リポジトリ名）/`

## ご注意

人工知能が翻訳しているのではありません。JMdict（日本語—英語）と Digital Pāḷi Dictionary（パーリ語—英語）を、英語を介してつなぎ、意味の重なりから候補を機械的に選んでいます。的外れな候補や否定形が混じることがあります。英訳を手がかりに、ご自身でふさわしい語をお選びください。学術的・宗教的な用途では、必ず原典や専門の辞書で確認してください。
